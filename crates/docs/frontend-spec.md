# Bopogram 正式版前端規格（第 6 階段）

2026-11-19 經使用者確認。範圍只含 Windows 前端；Rust 引擎移植另開規格。

## 目標與範圍

讓前端達到能每天在所有常用程式裡使用的水準，使用習慣以微軟新注音為準。

不做：已送出文字的重新轉換（違反「已送出的文字絕對不回頭修改」）、任何網路功能、
手寫、雲端詞庫。選字邏輯一律留在引擎。

## 架構

| 元件 | 職責 |
|---|---|
| `bopogram_ime.dll`（x64 與 x86） | TSF：收鍵、顯示組字與候選、送出。不載入模型、不做重運算 |
| `bopogram-host.exe`（x64，每位使用者一個） | 管理引擎與具名管線；日後 Rust 引擎直接放進 host |
| `bopogram-settings.exe` | 設定視窗 |
| `bopogram-protocol`（crate） | DLL 與 host 共用的協定：請求、回應、管線名稱、host 自身錯誤的標記 |

協定（`prototype/docs/frontend-handoff.md`）是前端與引擎之間的合約：
引擎從 Python 換成 Rust 時前端不需要改。

## 功能規格

| 項目 | 正式版 |
|---|---|
| 按鍵規則 | 對齊新注音；補上 Shift+空白鍵 全形／半形 |
| 組字區 | 文件內直接顯示；底線樣式跟隨深色／淺色主題 |
| 候選視窗 | 滑鼠點選與滾輪；每個螢幕各自的 DPI；深色／淺色主題；字型大小可調；避開螢幕邊緣；改善定位 |
| 不自繪候選的程式 | 支援 TSF 的 UI-less 模式 |
| 引擎啟動中 | 先在組字區顯示注音符號，就緒後補送，不掉字 |
| 上文 | TSF 讀游標前文字；讀不到時改用本輸入法在該文件最近送出的內容 |
| 模式圖示 | 自行繪製的正式圖示檔（工作列與 Win+空白鍵清單） |
| 32 位元程式 | 支援（`x86\bopogram_ime.dll`） |
| AppContainer 程式 | 支援：管線開放給 App 套件；來自 AppContainer 的連線一律關閉學習與打字紀錄 |
| 系統管理員身分執行的程式 | host 於登入時自動啟動（`HKCU\...\Run`），因此可直接使用 |
| 密碼欄位 | 停用、不學習、不記錄；加進自動測試 |
| 設定 | 選字風格、個人化學習、打字紀錄、計時紀錄、選字鍵、每頁候選數、候選字型大小、預設中英、Shift 切換開關、清除個人化資料 |
| 除錯 | 引擎 `--trace`（記錄內容，手動開關）；前端計時紀錄（只記耗時，24 小時後自動關閉） |
| 錯誤防護 | panic 不穿出 DLL；同一程式內連續出錯就自動停用自己 |

## 非功能規格

- 前端自身每鍵 P95 ≤ 5 ms（不含引擎與應用程式重繪）；含引擎往返 P95 ≤ 20 ms；
  單次按鍵不得卡住應用程式超過 200 ms（逾時規則照 handoff）。
- DLL 讓每個程式增加的記憶體 ≤ 5 MB。
- 沒有網路連線；密碼欄位的內容不送進引擎；個人資料只存在本機；管線只接受同一位使用者。
- 依賴只有 windows-rs 與 serde_json；新增依賴先登記 `THIRD_PARTY.md` 並告知使用者。
- 不參考任何輸入法專案的原始碼；TSF 知識只取自微軟文件與 windows-rs 文件。

## 安裝

維持 PowerShell 腳本（`crates/install/`），由使用者以系統管理員身分執行。
不做 MSI、不簽章，等要散布時再決定。

## 相容性測試清單

記事本（64／32 位元）、Word、命令提示字元、Windows Terminal、檔案總管重新命名、
Edge／Chrome／Firefox（一般與密碼欄位）、VS Code、Discord、LINE、全螢幕遊戲（UI-less）、
系統管理員身分執行的程式、開始功能表搜尋。

## 里程碑

| # | 內容 | 驗收 |
|---|---|---|
| M1 | 共用協定 crate、前端計時紀錄、x86 建置、測試整理 | 現有功能不變，沙盒通過，取得實際延遲數據 |
| M2 | 正式候選視窗與 UI-less 模式 | 滑鼠選字、高 DPI、深色主題、全螢幕程式可用 |
| M3 | 引擎連線：啟動中不掉字、上文備援、AppContainer、登入時啟動 host | 剛開機就打字不會出現英文；開始功能表搜尋可用 |
| M4 | 正式圖示與完整設定程式 | 設定全部生效 |
| M5 | 安裝、更新、移除定版 | 更新不必登出，移除乾淨 |

每個里程碑先在沙盒測試，再由使用者安裝到主系統。
